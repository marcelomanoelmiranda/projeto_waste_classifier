# Classificação de Imagens de Resíduos usando Deep Learning

## 📌 Visão Geral do Projeto
Este projeto tem como foco a **classificação de imagens de resíduos utilizando técnicas de deep learning**, com o objetivo de apoiar processos de separação e reciclagem de lixo por meio de inteligência artificial.

O estudo avalia e compara o desempenho de diferentes **arquiteturas de Redes Neurais Convolucionais (CNN)** aplicadas a tarefas de classificação de imagens, utilizando um conjunto de dados público sobre resíduos.

Este projeto foi desenvolvido como parte do **Curso de Pós-Graduação em Ciência de Dados**.

---

## 🎯 Objetivos
- Aplicar técnicas de deep learning para classificar imagens de resíduos
- Comparar o desempenho de múltiplas arquiteturas de CNN
- Avaliar os modelos por meio de métricas de acurácia e matriz de confusão
- Apoiar soluções inteligentes para gestão e reciclagem de resíduos

---

## 🧠 Modelos e Arquiteturas
As seguintes arquiteturas de deep learning pré-treinadas foram utilizadas e avaliadas:
- **DenseNet-121**
- **VGG16**
- **MobileNetV2**

Foi utilizada a técnica de **Transfer Learning** para melhorar o desempenho e reduzir o tempo de treinamento.

---

## 📂 Conjunto de Dados (Dataset)
- **Nome:** Waste Classification Data
- **Fonte:** Kaggle
- **Link:** https://www.kaggle.com/datasets/techsash/waste-classification-data

O dataset contém imagens rotuladas de diferentes categorias de resíduos, sendo adequado para tarefas de classificação supervisionada.

---

## 🧪 Metodologia
1. Carregamento e pré-processamento dos dados
2. Redimensionamento e normalização das imagens
3. Treinamento dos modelos utilizando Transfer Learning
4. Avaliação dos modelos por meio de:
   - Acurácia
   - Loss (Perda)
   - Matriz de Confusão
5. Comparação de desempenho entre as arquiteturas

---
